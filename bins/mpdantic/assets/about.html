MPDantic

Audits and repairs a Volumio player's music library for MPD, one folder at a time or the whole library from its root: what MPD's update meets under a folder and the .mpdignore lines that keep the junk out; CUE sheets read the way MPD reads them, with the repairs a sheet's text allows; the tags the Albums view is built from, read as written and judged by MPD's own rules. Every write is shown whole first, confirmed once, journaled, and undone from the same page; on a network share it goes through a read-write mount made for the write and released after.

This playerfor an issue

What this player is and how its library sits against MPD's output buffer, as one block to paste into an issue. It names no share, path or credential, only counts. The album query is measured on your say: MPD is asked for every song with every tag, as Volumio's album view asks, and the reply is counted as it streams, never kept; on a large library MPD works for a few seconds.
