Repair tags in this folder
The audio files of the folder in hand, not the folders under it. The album artist and the date written where MPD reads them, text that is UTF-8 read as Latin-1 decoded, a tag given twice kept once, an ID3v2 tag from ID3v1, and the Album, Album artist and Date every file gets where the files disagree. Each file is shown with its changes before anything is written. DSF and DFF files are read, not written.
Edit tags file by file
Every audio file of the folder in hand as a grid, one column per field MPD reads. Type in a cell, or set a column for every file at once; an empty cell removes the key. Nothing leaves the page until Preview, which shows every change key by key; the write and the undo are the same as for the repairs.
MusicBrainz
Look up a release for the folder in hand from its album artist, album and track count. Pick one hit, then Preview shows the tags as they would be written file by file through the same path as the editor. A mix or dump that holds several albums is listed with what to do next, not refused. The public MusicBrainz site is used at one request per second unless a local mirror is set on the plugin's settings page.
Organise
One album per folder. Scan the folder in hand, then tick Move or Skip for each album. Preview shows the destinations; Write moves the selected files. Anything skipped stays here — the dump folder is not deleted.
Folder name
Rename the folder in hand from its album or album artist tags, or a name you type. The name is made safe for a share. Browse also offers Rename on each folder row. Nothing is written before the preview and Write; the undo gives the name back.
File names and tags
One pattern, either way: the files named from their tags, or the tags read from the file names. The placeholders are the fields of the grid; the text between them is taken as it is. A name is made safe for a share: slashes, colons and the characters Windows refuses become underscores. A sheet or a playlist in the folder that names a renamed file is rewritten with it. Nothing is written before the preview and Write; the undo gives the names back.

System This player, as one block for an issue: what it is, and how its library sits against MPD's output buffer. It names no share, path or credential, only counts. The album query is measured on your say: MPD is asked for every song with every tag, as Volumio's album view asks, and the reply is counted as it streams, never kept; on a large library MPD works for a few seconds. The block is in English, for the maintainers who read it.
